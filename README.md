# Canadian Banking Excel Data Quality, Transformation & Statistical Analytics Project

## Project Overview

This is an end-to-end Excel portfolio project built for Canadian finance analyst, FP&A analyst, data analyst, reporting analyst, and BI analyst roles.

The project uses a synthetic Canadian banking dataset to demonstrate how raw financial data can be cleaned, prepared, validated, transformed, analyzed, and presented inside Microsoft Excel.

The workbook covers:

- Raw data profiling
- Power Query cleaning and transformation
- Data quality validation
- Relationship and lookup checks
- Reconciliation controls
- Feature engineering
- PivotTable analysis
- Excel Analysis ToolPak statistical analysis
- KPI dashboarding
- Executive reporting

---

## Business Scenario

A Canadian banking analytics team needs reliable customer, account, transaction, loan, credit card, campaign, and branch performance data before producing executive reports.

The goal of this project is to turn messy raw banking data into clean, analysis-ready tables and management-ready insights.

## Key Analysis Areas

### 1. Data Cleaning and Preparation

The workbook profiles and cleans raw banking data by handling:

- Duplicate IDs
- Missing values
- Invalid dates
- Invalid emails
- Invalid postal codes
- Inconsistent province names
- Orphan customer/account/branch/product relationships
- Negative or unusual financial values
- Data quality exceptions

### 2. Power Query Transformation

Power Query is used to create repeatable cleaning steps while preserving the raw source data.

Examples of transformations include:

- Trim and clean text
- Standardize case formatting
- Convert data types
- Validate lookup relationships
- Remove duplicate master records
- Create cleaned reporting tables
- Flag records requiring review

### 3. Reconciliation Controls

The workbook includes reconciliation checks to compare raw and cleaned data.

Controls include:

- Raw vs cleaned row counts
- Expected duplicate removals
- Transaction exclusions
- Controlled exceptions
- Financial total checks
- Failed control count

### 4. Feature Engineering

The project creates analytical features across customer, account, transaction, loan, credit card, campaign, and branch data.

Feature examples include:

- Customer age and tenure
- Income bands
- Credit score bands
- Account activity indicators
- Monthly transaction summaries
- Loan risk indicators
- Credit card utilization bands
- Campaign uplift metrics
- Branch performance metrics

### 5. Statistical Analysis

Excel Analysis ToolPak is used for selected business-relevant statistical analysis.

Completed methods include:

- Descriptive Statistics
- Histogram
- Correlation
- Regression
- t-Test
- ANOVA Single Factor
- Moving Average
- Exponential Smoothing
- Rank and Percentile

The purpose is not just to run statistical tools, but to interpret the outputs in a finance and banking analytics context.

### 6. Dashboard and Executive Reporting

The final workbook includes a finance KPI dashboard and executive summary designed for management review.

Dashboard areas include:

- Customer base overview
- Account and balance KPIs
- Transaction trends
- Loan and credit card indicators
- Campaign performance
- Branch revenue performance
- Data quality exceptions
